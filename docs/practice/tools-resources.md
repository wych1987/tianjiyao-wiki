## 二、学习书籍体系

### 八字命理书籍

**入门级（3-6个月）**
- 《八字入门》：徐伟刚著，概念讲解清晰，案例丰富
- 《子平基础教程》：段建业著，系统性强，适合打基础
- 推荐理由：语言通俗，配图丰富，避免过早接触复杂理论

**进阶级（6-12个月）**
- 《子平真诠评注》：徐乐吾评注，深入解读经典
- 《渊海子平现代解读》：沈竹礽著，古今结合
- 学习要点：重点理解十神关系和格局分析

**高级研究**
- 《三命通会》精选：选择现代注解版本
- 《滴天髓阐微》：任铁樵注，理论精深
- 研究方法：配合实际案例反复验证

**古籍经典**
- 《穷通宝鉴》：重点学习调候理论
- 《神峰通考》：张楠著，格局分析独特

### 紫微斗数书籍

**基础教材**
- 《紫微斗数精成》：基础概念完整
- 《现代紫微斗数全集》：实例丰富

**进阶读物**
- 《紫微斗数全书》注解版
- 《飞星紫微斗数》：创新理论

### 基础理论书籍

**阴阳五行**
- 《五行大义》现代解读
- 《阴阳五行学说》：结合现代科学解释

**易经研究**
- 《周易译注》：周振甫译注，权威版本
- 《易经入门》：傅佩荣著，适合初学者

### 跨学科书籍

**心理学相关**
- 《荣格心理学与易经》
- 《性格心理学》：帮助理解命理中的性格分析

**统计学相关**
- 《统计学基础》：理解命理验证方法
- 《数据分析实战》：Python版，适合技术型学习者

### 视频课程平台

**主流平台课程特色**
- B站学习区：免费公开课与古籍精讲丰富，适合入门试听

## 四、实践工具配置

### 笔记与知识管理软件
- **Obsidian**：基于双向链接构建干支、十神、星曜与真实命例的知识图谱
- **Notion**：建立结构化命例数据库（支持按日主、格局、流年事件多维筛选）
- **飞书文档 / 语雀**：适合团队协作整理学习笔记与案例复盘

### 案例管理
- 建立标准化案例记录模板（记录公历出生时间、出生地经纬度、真太阳时校正与已知验证事件）
- 使用电子表格或数据库管理基础样本特征
- 开启本地备份与云端加密同步，妥善保护个人及他人隐私信息

### 数据分析
- Python + pandas：自定义样本特征统计与规律验证
- SPSS / R：相关性与分类统计分析

## 五、技术工具（进阶选择）

### 历法与排盘开源库
- **sxtwl（Python）**：寿星天文历 C++ 底层绑定，适合高精度节气交接时刻与公农历计算
- **lunar-python（Python）**：常用的中国传统历法库，支持四柱干支、节气、神煞与建除十二神换算
- **zhdate（Python）**：轻量级公历/农历日期互转工具
- **iztro（JavaScript / TypeScript）**：开源紫微斗数星盘计算库，适合前端或 Node.js 排盘原型开发

### 数据可视化
- Matplotlib：制作命盘图表
- ECharts：交互式展示
