## 二、地支概述

### 1.1 地支的起源
地支作为中国古代历法系统的核心组成部分，其起源可追溯至殷商时期。根据《史记·天官书》记载，地支最初用于记录月相变化周期，后逐渐发展为完整的时空坐标系统。地支共计十二位：子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥，这一系统在商代甲骨文中已有明确记载。

从哲学层面分析，地支的创立体现了古人"观象授时"的智慧。《周髀算经》云："天地之数，起于子，终于亥。"十二地支完整地反映了天地阴阳消长的循环规律，构成了中国传统时空观的基础框架。在《淮南子·天文训》中，详细记载了地支与二十八宿的对应关系，展现了古人将天文观测与地理方位完美结合的精妙思维。

### 1.2 十二生肖的由来
十二生肖与地支的配属关系，最早完整记载于东汉王充的《论衡》。其中《物势篇》明确记载："寅，木也，其禽虎也......"等十二地支与动物的对应关系。这种配属源于古人对动物活动规律的观察总结：

子时（23-1时）鼠类活动频繁，故配鼠；
丑时（1-3时）牛反刍准备耕作，故配牛；
寅时（3-5时）虎最凶猛，故配虎；
卯时（5-7时）玉兔仍在月宫，故配兔；
辰时（7-9时）神龙行雨之时，故配龙；
巳时（9-11时）蛇出洞觅食，故配蛇；
午时（11-13时）阳气至极马奔驰，故配马；
未时（13-15时）羊吃草最佳时，故配羊；
申时（15-17时）猴群活跃，故配猴；
酉时（17-19时）鸡归巢，故配鸡；
戌时（19-21时）狗守夜，故配狗；
亥时（21-23时）猪酣睡，故配猪。

### 1.3 地支与月令的关系
地支与月份的对应关系称为"月建"，这一制度在《礼记·月令》中有系统记载。正月建寅，二月建卯，以此类推至十二月建丑。这种对应关系体现了太阳视运动黄道十二宫的划分：

寅月对应立春至惊蛰，为孟春；
卯月对应惊蛰至清明，为仲春；
辰月对应清明至立夏，为季春；
巳月对应立夏至芒种，为孟夏；
午月对应芒种至小暑，为仲夏；
未月对应小暑至立秋，为季夏；
申月对立秋至白露，为孟秋；
酉月对白露至寒露，为仲秋；
戌月对寒露至立冬，为季秋；
亥月对立冬至大雪，为孟冬；
子月对大雪至小寒，为仲冬；
丑月对小寒至立春，为季冬。

### 1.4 地支的天文基础
从天文学角度考察，地支系统建立在岁星（木星）运行周期基础上。木星绕太阳公转周期约11.86年，古人取其约数12年为一纪，将黄道划分为十二宫，每宫对应一个地支。同时，地支还反映了北斗七星斗柄的指向变化，《鹖冠子》记载："斗柄东指，天下皆春；斗柄南指，天下皆夏；斗柄西指，天下皆秋；斗柄北指，天下皆冬。"

## 二、十二地支详解

### 2.1 子水
**属性**：阳水
**象征**：代表冬季最寒之时，象征新生与潜伏
**月令**：农历十一月
**藏干**：癸水（本气）
子水为十二地支之首，具有"至阴至寒"的特性。《三命通会》指出："子为墨池，其色黑，其象为水，位居正北。"子水虽属阳支，但内含纯阴之癸水，体现了阴阳消长与演化的深意。

### 2.2 丑土
**属性**：阴土
**象征**：寒冬土壤，蓄势待发
**月令**：农历十二月
**藏干**：己土（本气）、癸水（中气）、辛金（余气）
丑土为金库，内含水之余气，金之墓库。《渊海子平》云："丑为柳岸，其色黄，中有金水之气。"

### 2.3 寅木
**属性**：阳木
**象征**：初春生机，万物始生
**月令**：农历正月
**藏干**：甲木（本气）、丙火（中气）、戊土（余气）
寅为广谷，象征山林茂盛。《三命通会》称："寅为功曹，其色青，内含甲丙戊。"

### 2.4 卯木
**属性**：阴木
**象征**：仲春繁盛，花木扶疏
**月令**：农历二月
**藏干**：乙木（本气）
卯为琼林，代表柔木繁茂。《渊海子平》指出："卯为琼林，其色青，纯乙木之气。"

### 2.5 辰土
**属性**：阳土
**象征**：春末湿土，水库所在
**月令**：农历三月
**藏干**：戊土（本气）、乙木（中气）、癸水（余气）
辰为草泽，水土交融之地。《三命通会》云："辰为水库，其色黄，中有戊乙癸。"

### 2.6 巳火
**属性**：阴火
**象征**：初夏暖阳，火势初起
**月令**：农历四月
**藏干**：丙火（本气）、戊土（中气）、庚金（余气）
巳为大驿，象征火势渐旺。《渊海子平》称："巳为炉火，其色红，内含丙戊庚。"

### 2.7 午火
**属性**：阳火
**象征**：盛夏烈日，火势最旺
**月令**：农历五月
**藏干**：丁火（本气）、己土（余气）
午为烽堠，象征极盛之火。《三命通会》云："午为火正，其色赤，内含丁己。"

### 2.8 未土
**属性**：阴土
**象征**：夏末燥土，木库所在
**月令**：农历六月
**藏干**：己土（本气）、丁火（中气）、乙木（余气）
未为花园，象征土中藏火。《渊海子平》指出："未为木库，其色黄，中有己丁乙。"

### 2.9 申金
**属性**：阳金
**象征**：初秋肃杀，金气始生
**月令**：农历七月
**藏干**：庚金（本气）、壬水（中气）、戊土（余气）
申为名都，象征刚锐之金。《三命通会》称："申为金刚，其色白，内含庚壬戊。"

### 2.10 酉金
**属性**：阴金
**象征**：仲秋金旺，肃杀之气
**月令**：农历八月
**藏干**：辛金（本气）
酉为寺钟，象征纯金之气。《渊海子平》云："酉为金正，其色白，纯辛金之气。"

### 2.11 戌土
**属性**：阳土
**象征**：秋末燥土，火库所在
**月令**：农历九月
**藏干**：戊土（本气）、辛金（中气）、丁火（余气）
戌为烧原，象征火库燥土。《三命通会》指出："戌为火库，其色黄，中有戊辛丁。"

### 2.12 亥水
**属性**：阴水
**象征**：初冬寒水，水势渐旺
**月令**：农历十月
**藏干**：壬水（本气）、甲木（余气）
亥为悬河，象征大水奔流。《渊海子平》称："亥为水正，其色黑，内含壬甲。"

## 三、地支属性

### 3.1 阴阳分类
地支阴阳划分遵循"奇阳偶阴"原则：
**阳支**：子、寅、辰、午、申、戌（奇数位）
**阴支**：丑、卯、巳、未、酉、亥（偶数位）
《周易·系辞》云："阳卦奇，阴卦偶。"地支阴阳属性体现了事物发展的两种基本态势。

### 3.2 五行归属
地支五行分配体现四季流转：
**木**：寅、卯（春）
**火**：巳、午（夏）
**金**：申、酉（秋）
**水**：亥、子（冬）
**土**：辰、未、戌、丑（四季月）

### 3.3 四季分类
春：寅卯辰（木旺）
夏：巳午未（火旺）
秋：申酉戌（金旺）
冬：亥子丑（水旺）

### 3.4 方位对应
子：正北
卯：正东
午：正南
酉：正西
其他地支分布在四维方位，构成完整的方位系统。

### 3.5 时辰对应
古代将一天分为十二时辰，每时辰对应一个地支：

## 四、地支藏干理论与速记歌诀

### 4.1 藏干的概念与哲学内涵
地支藏干是传统命理学的核心理论，古人称“天干为天元，地支为地元，支中所藏天干为人元”，统称“三元”。这一理论在《渊海子平》与《三命通会》中有精辟阐述：天干展现于外，如树之干叶；地支承载于下，如树之根脉；而地支中所藏的天干，则是深埋于地下的生命养分与深层潜能。

藏干理论揭示了一个关键规律：**地支不是单一五行的机械切片，而是包含多种气机交织的复合体。**

### 4.2 经典《地支藏干歌》（必背歌诀）
这是历代命理学者通用的经典速记歌诀：

```text
子藏癸水在其中，丑中癸辛己土同。
寅藏甲木并丙戊，卯中乙木独相逢。
辰藏乙木癸戊土，巳中庚金丙戊从。
午藏丁火并己土，未中乙木己丁同。
申藏庚金壬戊位，酉中辛金独相逢。
戌藏辛金丁戊土，亥中壬水甲木存。
```

### 4.3 藏干构成与力量分布表（本气 / 中气 / 余气）
藏干依力量大小与气机来源分为三个层次：
- **本气（约占 60% 权重）**：与该地支主干五行完全一致的根本气机，力量最强；
- **中气（约占 30% 权重）**：该地支所属三合局的五行长生之气，或墓库藏气；
- **余气（约占 10% 权重）**：上一月节气退气后的残留力量。

| 地支 | 本气（主导 60%） | 中气（次要 30%） | 余气（残存 10%） | 气机来源与合局关系 |

| **子** | **癸水** | 无 | 无 | 纯水之精，冬至一阳生，纯阴之癸水汇聚 |

| **寅** | **甲木** | **丙火** | **戊土** | 甲木参天，丙火于此长生（寅午戌火局），戊土寄生 |
| **卯** | **乙木** | 无 | 无 | 纯木之秀，仲春花草繁盛，气机纯一 |
| **辰** | **戊土** | **乙木** | **癸水** | 湿土之库，乙木为春末余气，癸水为申子辰水库之气 |
| **巳** | **丙火** | **戊土** | **庚金** | 烈火初炎，戊土得火而生，庚金于此长生（巳酉丑金局） |
| **午** | **丁火** | **己土** | 无 | 盛夏阳极生阴，丁火为主，己土火土同宫寄生 |

### 4.4 藏干透出与通根的判断法则
在八字排盘与命理判断中，藏干决定了格局的真伪与用神的力量：
1. **藏干透出**：当天干出现的字与某地支藏干相同时，称“透出”。例如八字天干见“甲木”，日支见“寅”，寅中藏甲，即为“本气透出”，此时甲木力量百倍显露；
2. **通根得气**：天干依赖地支藏干作为根基：
   - **强根（本气根）**：如甲木坐寅、庚金坐申，根基深厚，百折不挠；
   - **中气根**：如丙火通根于寅中丙火、庚金通根于巳中庚金，借生发之力立足；
   - **余气根**：如乙木通根于辰中乙木、辛金通根于戌中辛金，虽然有根但较为单薄，岁运冲克时需防拔根。
3. **十神定位**：八字中的十神（正官、七杀、正印、偏印、食神、伤官、正财、偏财、比肩、劫财）都是由天干对日主所透出的地支藏干综合测算而得。

## 五、地支相互作用关系全解

地支之间的作用关系比天干更为复杂多变，主要包含：**六合、三合局、三会局、六冲、相刑、六害（相害）、相破**。

### 5.1 地支六合（阴阳和合）
六合象征日月相会，主结纳、亲善、聚合、绊住：

| 六合组合 | 合化五行 | 象征意涵 | 成立与引化要点 |
|:---|:---:|:---|:---|
| **子丑合** | **土**（亦可论水土交融） | 寒土蓄水，暗潮涌动 | 天干透出己土易化土；若水旺则易为湿泥合拌 |
| **寅亥合** | **木** | 水木相生，生机勃发 | 亥水生寅木，生合力量极强，水旺木浮时需注意 |
| **卯戌合** | **火** | 木火通明，热土生化 | 卯木引动戌中丁火，多主暗有热情、文明礼乐 |
| **辰酉合** | **金** | 湿土生金，刚柔并济 | 辰土生酉金，土金相涵，金气显露 |
| **巳申合** | **水**（刑中带合） | 火金激荡，合而化水 | 既有相合之意，又兼刑冲克制，关系常先好后变 |
| **午未合** | **土**（亦论火土同源） | 日月丽天，燥烈相吸 | 午火生未土，火土两旺，主性格热烈、行事果决 |

### 5.2 地支三合局（长生、帝旺、墓库三位一体）
三合局是五行运行全过程的凝聚，力量仅次于三会方局：

| 三合局 | 合化五行 | 构成地支与职能 | 命理核心特质 |
|:---|:---:|:---|:---|
| **申子辰** | **水局** | 申（长生）+ 子（帝旺）+ 辰（墓库） | 奔流不息，智慧通达，多主远行、流动、变通 |
| **寅午戌** | **火局** | 寅（长生）+ 午（帝旺）+ 戌（墓库） | 烈火升腾，文采焕发，多主热情、张扬、名气 |
| **亥卯未** | **木局** | 亥（长生）+ 卯（帝旺）+ 未（墓库） | 枝繁叶茂，仁德仁慈，多主生长、艺术、柔韧 |
| **巳酉丑** | **金局** | 巳（长生）+ 酉（帝旺）+ 丑（墓库） | 锋锐坚挺，义气沉稳，多主决断、严谨、财气 |

> **半合与拱合**：缺少其中一支称为“半合”（如申子半合水、子辰半合水为“生半合”与“墓半合”）；缺中神中位者（如申辰、寅戌）称为“拱合”，待岁运引动中神方能成局。

### 5.3 地支三会局（同方专旺气）
三会局汇聚一整个季节与方位的纯粹力量，力量最为专一雄厚：
- **寅卯辰 会 东方木**（春季三月，木气极致）
- **巳午未 会 南方火**（夏季三月，火气极致）
- **申酉戌 会 西方金**（秋季三月，金气极致）
- **亥子丑 会 北方水**（冬季三月，水气极致）

### 5.4 地支六冲（对宫相击）
六冲为方位正对（相隔 180 度）、五行属性正克，多主**变动、冲突、散离、碰撞、健康起伏**：

| 六冲组合 | 对抗五行与方位 | 命理典型反应与象义 |
|:---:|:---|:---|
| **子午冲** | 水克火（正北冲正南） | 水火激荡，心肾不交，情绪波动大，多涉及事业环境与人际变迁 |
| **丑未冲** | 土土相冲（东北冲西南） | 库开气乱，脾胃虚损，涉及不动产、居所或暗藏人事矛盾 |
| **寅申冲** | 金克木（东北冲西南） | 道路奔波，驿马交驰，易有筋骨擦碰、换工作或长途出行 |
| **卯酉冲** | 金克木（正东冲正西） | 门户相冲，桃花易碎，多涉及人际纠纷、感情分合或手足之伤 |
| **辰戌冲** | 土土相冲（东南冲西北） | 水库火库激荡，多为环境动迁、房产交割，行事波折但易见转折 |
| **巳亥冲** | 水克火（东南冲西北） | 驿马相克，心思多虑，喜好助人却易招口舌，多走动出差 |

### 5.5 地支相刑（内部矛盾与规则制约）
相刑多主内部折磨、是非纠葛、官非或性格纠结：
1. **无恩之刑（寅、巳、申）**：知恩反怨，互相猜忌，行事刚毅易折，防文书与车马损伤；
2. **恃势之刑（丑、戌、未）**：依仗权势或固执己见导致冲突，多涉及财产合同纠纷；
3. **无礼之刑（子、卯）**：水多木漂或缺乏界限感，多涉及伦常礼仪、感情争执或隐私困扰；
4. **自刑（辰辰、午午、酉酉、亥亥）**：自我内耗、纠结自责、想不开或因过度执念导致失误。

### 5.6 地支相害（六害）与相破
- **六害（穿害）**：源于六合被冲（如子丑合，未冲丑，故子未相害）。包含：**子未害、丑午害、寅巳害、卯辰害、申亥害、酉戌害**。多主暗中作梗、骨肉不睦、身心劳碌。
- **相破**：内部结构轻度摩擦或轻微损耗。包含：**子酉破、寅亥破、辰丑破、午卯破、申巳破、戌未破**。

## 九、排盘速算技巧：左手地支掌诀图解

在传统命理实操与排盘中，历代学者与专业预测者普遍使用**左手掌诀**（掐指算命）。十二地支固定分布在左手的四指关节上，顺时针排列成一圈：

```text
               【中指尖】
                 午火
        【食指尖】 ┌─┐ 【无名指尖】
          巳火   │ │   未土
        ┌───┐   │ │   ┌───┐ 【小指尖】
        │辰土│   │ │   │   │   申金
        ├───┤   ├──┤   ├───┤   ├───┤
        │卯木│   │ │   │   │   酉金
        ├───┤   ├──┤   ├───┤   ├───┤
        │寅木│   │ │   │   │   戌土
        └───┘   │ │   └───┘   ├───┤
                 │ │           │亥水│
                 └─┘           └───┘
               丑土     子水
            【中指根】 【无名指根】
```

### 掌诀推演速记绝窍：
1. **六冲看对立直线**：在手掌上呈对立直线的地支即为六冲（子午正对、丑未正对、寅申正对、卯酉正对、辰戌正对、巳亥正对）；
2. **六合看水平横线**：手指横向平行的相邻指节两两相合（子丑合土、寅亥合木、卯戌合火、辰酉合金、巳申合水、午未合土）；
3. **三合看三角形**：申-子-辰三点连成等腰三角形即为水局，寅-午-戌为火局，亥-卯-未为木局，巳-酉-丑为金局；
4. **三会看同侧整排**：寅卯辰在食指为春季木局，巳午未在中指无名指尖为夏季火局，申酉戌在小指为秋季金局，亥子丑在掌根为冬季水局。

熟练使用左手掌诀后，无需笔纸即可瞬间心算任何干支的刑冲会合状态。

## 十、常见问题解答（FAQ）

### Q1：十二地支对应的现代时间怎么记最简单？
**答**：记住“午时为正午 11:00 至 13:00”和“子时为深夜 23:00 至 01:00”，其余时辰按地支顺序（子丑寅卯辰巳午未申酉戌亥）每两小时顺推即可。例如上午 9-11 点为巳时，下午 15-17 点为申时。

### Q2：地支藏干中，“本气”、“中气”和“余气”在分析时有什么区别？
**答**：本气力量最强（约占 60% 权重），中气次之（约占 30%），余气最弱（约占 10%）。当测算八字强弱、定格局或抓用神时，若天干有字与地支本气同气，称为“通根得气”，力量最为稳固；若只通根于余气，力量则相对单薄，遇岁运冲克时容易受损。

### Q3：地支六冲一定代表运势不好吗？
**答**：不一定。六冲的核心是“变动”与“引动”。若八字原局某五行忌神过旺，逢冲反而可能冲去忌神（称“冲去忌神大吉”）；若冲散喜用神或引发用神受克，才体现为波折、破耗或身体不适。因此，冲是中性的能量激活方式，吉凶取决于格局喜忌。

### Q4：地支三合局只要凑齐三个字就一定能合化成功吗？
**答**：不一定。三合成局必须看月令环境与天干透出的引化之气。例如寅午戌三合火局，若生于夏季巳午月，天干透出丙火或丁火，火势纯正，合化极易成功；若生于亥子大雪月，天干透水无火，则往往只论合拌合聚，火气无法彻底化出。

### Q5：八字里的“地支相穿/相害”究竟怎么理解？
**答**：相害本质上是“破坏对方的六合”。比如子丑本想合为一家，未土跑来冲散丑土，子水就会对未土怀恨在心，形成“子未穿害”。因此相害往往体现为无心之失、背后阻力、亲友误解或情绪隐痛，其杀伤力往往比正面六冲更为隐蔽。
